Current-state map for coding agents. Keep it a snapshot: edit entries, do not append history.

## Build

JDK 21 (Robolectric for SDK 36 needs it), Android SDK platform 37. `./gradlew assembleDebug test`. No device here: unit tests only, Jonas tests on his phone. Release signing: `signingConfigs.release` reads `DNSBM_RELEASE_*` from `~/.gradle/gradle.properties` or env (key `~/.config/dns_blocklist_merger/release.jks` on Jonas's machine, never in the repo); without them the release build is unsigned.

## Modules

- `core/` (pure Kotlin, JUnit):
  - `BlocklistParser` reads adblock (`||domain^`), hosts and plain domain lists, line by line. `DomainNormalizer` lowercases, strips scheme/port/path/trailing dot, converts IDN to punycode and drops IPs, single-label and reserved names.
  - `InputText` cleans phone input (Gboard puts a space after every dot): `withoutWhitespace` for URLs, domains and the domain search; `withoutSpacesAfterDots` for the SMB path (folder names may contain spaces).
  - `Selection.compute` builds the output file (spec A5/A6). Priority 1 is the highest; priority value = lowest priority number - p + 1. Highest-priority domains are always written (only if they alone exceed the limit, they are filled by rank too and the start page shows „P1 gekürzt“ with a hint), the rest by rank while it fits (`||domain^\n` bytes). With subdomain pruning a written parent replaces already written children. Returns `DomainInfo` per domain (rank, frequency, best priority, `DomainStatus`) for the UI.
- `app/` (Android, Compose, Material 3):
  - `App` / `AppContainer`: manual wiring of database, settings and repositories (`context.container`).
  - `data/`: Room `AppDatabase` (tables `blocklist`, `exception`, `output_domain`, `output_state`; schema JSON in `app/schemas/`). The domains of each list's last good download are files in `filesDir/lists/<id>.txt` (`DomainFileStore`), not table rows. `BlocklistRepository`: list CRUD and download status (`updateUrl` resets status, format and stored domains of a list), exceptions, `recompute(settings)` (runs `Selection`, stores per-domain rows and the output numbers), `renderOutput()`, paging of domains. `SettingsRepository`: DataStore settings with spec defaults and range checks; size and weights are stored together in one edit (`setOutput`, #21); no password there.
  - `download/`: `BlocklistDownloader` (OkHttp, conditional GET with ETag/If-Modified-Since, streams into the parser, German error texts; empty body or no domains count as errors). `Refresher.refreshAll()` downloads every list, records success/304/error at the list (errors keep the last good domains) and recomputes the output.
  - `smb/`: `SmbTarget.parse` (`smb://host/share/dir/file`, also `//host/...` and `\\host\...`; a path ending on an existing folder writes `blocklist.txt` into it, `SmbjFiles.resolved`, #27), `SmbWriter` (credential check; no size guard, the size setting limits the file; German error texts via `messageFor`), `SmbjFiles` (smbj with BouncyCastle provider; on a dropped connection (`SmbWriter.isDroppedConnection`, e.g. a reset during negotiation) retries with the next `negotiationFallbacks()` config: smbj default, then without SMB 3.1.1, then SMB 2.x with multi-protocol negotiate; writes `<file>.tmp` then renames onto the target; probe = create and delete a test file), `AesGcmCipher` + `PasswordStore` (password AES-GCM encrypted with an Android Keystore key, stored base64 in the settings DataStore; undecryptable reads as no password).
  - `OutputPublisher`: renders the output, writes it via `SmbWriter`, records `writtenAt`/`writeError`.
  - `work/`: `UpdateFlow.run()` = refresh all lists + recompute + write to the FRITZ!Box when a path is set; used by `DailyUpdateWorker` and by the "Aktualisieren" button. `DailyScheduler` enqueues unique periodic work (1 day, initial delay to the set time, network required; KEEP at app start, CANCEL_AND_REENQUEUE when the time changes). Worker retries up to 3 times when writing failed. `App` is a `Configuration.Provider` with `AppWorkerFactory`; the default WorkManager initializer is removed in the manifest.
  - `AppController`: app-wide scope, runs refresh/recompute/write/save-as jobs one at a time (`busy` text, snackbar `messages`).
  - `ui/`: `AppNavigation` (routes home, domains, settings; „Speichern unter…“ uses `CreateDocument("text/plain")` with `blocklist.txt` and `AppController.saveAs`; ViewModels built with `viewModel { }` from the container), `SubScreen` (back-arrow scaffold), `Format.kt` (German number/date formats). `ui/home/`: start page after concept B (output card with usage meter; meter, „von … KB“ and „gekürzt“ use the limit the output was computed with (`OutputStateEntity.maxBytes`), not the just-saved setting, #21; domains link, lists by priority with −/+ stepper; tap on name/URL shows the full URL, pencil icon edits the URL inline in the card and then refreshes, bin icon removes; error box only at the list; add list). Launcher icon: adaptive icon `res/mipmap-anydpi/ic_launcher.xml` (shield with three merging lines, plus monochrome layer); `LauncherIconTest` renders it to `app/build/screenshots/launcher-icon.png`. `ui/domains/`: paged domain list (domain names on one line, scroll sideways when long; tap copies the name into the exception field to edit it; info line, pill and button share one line, #28) (Room `PagingSource`, LIKE search, debounced) with status pills, exclude/allow, permanent exceptions card; every exception change triggers `AppController.recompute()`. `ui/settings/`: theme, size (field 5 KB-1 GB, default 4096 KB, warning above 4096 KB; slider ends at 4096 KB or the largest typed value, `sliderEndFor`), weights a/b (0-1000) saved together with „Übernehmen“, subdomain switch, daily time (M3 `TimePicker`), refresh now, SMB path/user; size/weights/switch changes recompute the output. `ui/theme/`: `AppTheme` (dynamic colours, `dynamic = false` for previews/tests), `Pill`.
- UI tests: Robolectric + Compose test rule with `@GraphicsMode(NATIVE)`; `saveScreenshot(name)` writes `app/build/screenshots/<name>.png` for a look by eye.
- Tests: `core` with plain JUnit; `app` with Robolectric (`@Config(sdk = [36])`, in-memory Room).
